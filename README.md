## ❓ FAQ

### ❓ Is it difficult to install the script on my own server?

**No.** Installation takes minimal time. We provide a clean distribution and detailed instructions for environment setup and domain licensing.

### ❓ Can I integrate other cryptocurrencies or payment gateways?

**Yes.** The architecture is built for easy scalability. The modular admin panel structure allows flexible management of available deposit and withdrawal methods.

### ❓ How are user funds and transactions protected?

The system implements protection against race conditions (transactions with row locking), HMAC signatures for API requests, Master PIN for transfers, and full security auditing in admin logs.

### ❓ Do I need a license for the script?

**Yes.** Nexus Core is commercial software protected by IonCube Loader. A license key is required for each domain.

### ❓ How many revenue streams does the platform generate?

**Five.** Exchange and swap fees, spot trading fees, merchant API revenue, acquiring fees, and virtual card subscriptions.

### ❓ Does it support virtual cards?

**Yes.** The system integrates with Payb to issue virtual Visa and Mastercard cards with full dashboard management (freeze, unfreeze, three tariff plans).

### ❓ Is the code open source?

**No.** Nexus Core is commercial software. The code is protected by IonCube Loader, but full documentation is available for developers who need to integrate or extend the system.

### ❓ What trading interface does it use?

**TradingView** charts with real order books, limit and market orders, plus automated rates via the Binance API.
